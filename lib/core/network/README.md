# Core Network

Network infrastructure, connectivity state streaming, and Supabase client wrapper per Blueprint §8.1 and §14.

## Files

- **`connectivity_service.dart`**: Online/offline state listener and connectivity stream.
- **`supabase_client.dart`**: Singleton Supabase client initialization wrapper.
- **`api_interceptor.dart`**: API logging, telemetry, and error transformation.
