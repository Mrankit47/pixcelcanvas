# Core Constants

Centralized constant declarations for PixelCanvas application configuration, limits, timeouts, and defaults.

## Files

- **`app_constants.dart`**: Canvas size limits, layer limits, undo stack depth, auto-save timers.
- **`api_constants.dart`**: Supabase endpoints, table names, storage bucket names.
- **`storage_constants.dart`**: Isar database names, collection identifiers, preference keys.
