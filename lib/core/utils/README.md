# Core Utils

Utility classes and algorithms for logging, debouncing, image processing, and color manipulation per Blueprint §8.1.

## Files

- **`logger.dart`**: Structured logging utility with log levels and redaction.
- **`debouncer.dart`**: Debouncer for auto-save and search queries.
- **`image_utils.dart`**: PNG encoding, scaling, and thumbnail generation helpers.
- **`color_utils.dart`**: HSL/RGB math, palette generation, and eyedropper color math.
