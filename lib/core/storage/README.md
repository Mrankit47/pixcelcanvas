# Core Storage

Local persistence abstractions for Isar database, FlutterSecureStorage, and SharedPreferences per Blueprint §11 and §17.

## Files

- **`local_database.dart`**: Isar database initialization and lifecycle wrapper.
- **`secure_storage.dart`**: Wrapper for encrypted key-value storage (auth tokens).
- **`preferences_service.dart`**: Wrapper for non-sensitive local user settings and flags.
