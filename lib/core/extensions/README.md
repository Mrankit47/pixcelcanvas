# Core Extensions

Utility extensions for built-in Flutter and Dart types per Blueprint §8.1.

## Files

- **`context_extensions.dart`**: BuildContext shortcuts for Theme, TextTheme, MediaQuery, Navigator.
- **`color_extensions.dart`**: Color conversion utilities (HEX string ↔ Color, ARGB, brightness).
- **`date_extensions.dart`**: DateTime formatting, relative time calculation, ISO-8601 helpers.
- **`string_extensions.dart`**: String validation, capitalization, hex parsing.
