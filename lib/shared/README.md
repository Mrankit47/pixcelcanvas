# Shared Module

Reusable UI components, layout structures, and micro-animations shared across features per Blueprint §8.1.

## Subdirectories

- **`widgets/`**: Branded PixelCanvas UI components (`PcButton`, `PcCard`, `PcTextField`, `PcBottomSheet`, `PcDialog`, `PcAvatar`, `PcSnackbar`, `PcLoading`, `PcEmptyState`, `PcErrorState`).
- **`layout/`**: Application scaffold wrapper and responsive breakpoint builders.
- **`animations/`**: Micro-animations (`FadeIn`, `SlideUp`, `ScaleBounce`).
