# Component Showcase Gallery

Visual gallery displaying all reusable branded components and their variants for testing and design QA per Blueprint §9.6.

## Gallery Contents

- **Buttons**: `PcButton` variants (primary, secondary, outlined, ghost, danger, small, medium, large, loading, disabled).
- **Cards**: `PcCard` variants (elevated, outlined, filled, interactive).
- **Text Inputs**: `PcTextField` variants (standard, password, search, multiline, error state).
- **Dialogs & Sheets**: `PcDialog` confirmation/alert helpers and `PcBottomSheet` containers.
- **Toasts**: `PcSnackbar` variants (success, error, warning, info).
- **Loaders**: `PcLoading` variants (circular, linear, skeleton).
- **States**: `PcEmptyState` and `PcErrorState` containers.
- **Avatars**: `PcAvatar` sizes, image/initials fallbacks, online indicator.
