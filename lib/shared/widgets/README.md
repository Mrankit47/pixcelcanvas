# Shared Widgets

Branded PixelCanvas UI component placeholders per Blueprint §9.6 and §24.5.

All shared components are prefixed with `Pc` and conform to design tokens defined in `lib/theme/`.

## Components

- **`pc_button.dart`**: Primary, secondary, text, and icon button variants.
- **`pc_card.dart`**: Elevated surface container for projects, templates, and gallery items.
- **`pc_text_field.dart`**: Form input field with focus state styling.
- **`pc_bottom_sheet.dart`**: Modal bottom sheet container with drag handle.
- **`pc_dialog.dart`**: Modal alert and input confirmation dialogs.
- **`pc_avatar.dart`**: User avatar display with fallback initials/icon.
- **`pc_snackbar.dart`**: Floating toast notification component.
- **`pc_loading.dart`**: Skeleton loaders and progress indicators.
- **`pc_empty_state.dart`**: Generic illustration + text empty state container.
- **`pc_error_state.dart`**: Error display container with retry CTA.
