# Help Center Architecture

> **Phase**: 7 – Step 5  
> **Version**: 1.0.0  

---

## 1. Overview

`HelpCenterManager` and `HelpSearchEngine` provide a searchable in-app documentation center:

- **Built-in Documentation**: Markdown articles for getting started, drawing tools, layer management, and animation timelines.
- **FAQ System**: Question & answer entries categorized by topic.
- **Unified Search**: Single search bar performing queries across articles, FAQs, tutorials, and command references.
