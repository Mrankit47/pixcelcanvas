# PixelCanvas v1.0 Release Notes

> **Version**: v1.0.0-RC1  
> **Release Date**: July 27, 2026  

---

## What's New in PixelCanvas 1.0

We are thrilled to announce the Release Candidate of **PixelCanvas 1.0**, a desktop-class pixel art editor built for artists, animators, and game developers!

### Key Features
- **Selection Engine**: Rubber-band selection, 8-handle scaling, and floating selection buffers.
- **Move / Copy / Cut / Paste**: Full clipboard serialization and floating buffer movement.
- **Shape Drawing Engine**: Pixel-perfect lines (Bresenham), rectangles, circles (Midpoint), and ellipses with filled/outlined modes.
- **Transform Engine**: 90°/180° rotations, horizontal/vertical flips, horizontal/vertical mirrors, and nearest-neighbor scaling.
- **PNG Import Pipeline**: Nearest-neighbor scaling, color reduction (16-256 colors), Floyd-Steinberg dithering.
- **Sprite Sheet Engine**: Automatic grid slicing, manual slicing, frame metadata, and tag organization.
- **Animation Timeline & Playback**: Multi-clip timeline (Idle, Walk, Run, Jump, Attack), pure Dart tick playback, loop modes (`Loop`, `Ping-Pong`, `Play Once`), and translucent red/green onion skinning.
- **Application Shell & Workspace Manager**: Multi-workspace project tabs, collapsible sidebars, status bar metrics, and command palette (`Ctrl+K`).
- **Project Dashboard**: Quick project launcher, search, category filters, and trash bin recovery.
- **Project Creation Wizard**: 5-step wizard flow and 6 built-in templates (Icons, Sprites, Tilesets, Animations, Portraits, UI Assets).
- **Settings & Shortcuts**: Customizable settings profiles, theme modes, and searchable keyboard shortcut rebinds with real-time conflict detection.
- **Help Center & Interactive Tutorials**: Step-by-step interactive tutorials and unified search.
- **Export Center & Packaging**: PNG, WebP, GIF, Sprite Sheet, and `.pixelcanvas` ZIP distribution packaging.
