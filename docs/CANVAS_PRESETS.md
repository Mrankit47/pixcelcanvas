# Canvas Presets Specifications

> **Phase**: 7 – Step 3  
> **Version**: 1.0.0  

---

## 1. Supported Canvas Resolutions

- **16×16**: Icons, small RPG sprites
- **32×32**: Classic 16-bit game sprites, item icons, portraits
- **48×48**: UI components, tiles
- **64×64**: High-detail character sprites, tilesets
- **96×96**: Portrait avatars
- **128×128**: Detailed animations, boss sprites
- **256×256**: Scene backgrounds, environments
- **512×512**: HD pixel art illustration
