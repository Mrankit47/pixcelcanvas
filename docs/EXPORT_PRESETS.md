> **Phase**: 7 – Step 6  
> **Version**: 1.0.0  

---

## 1. Built-in Preset Library

1. **Pixel Perfect (1x PNG)**: Unscaled 1:1 pixel grid PNG export.
2. **Web Optimized (2x WebP)**: 2x scaled compressed WebP image for web assets.
3. **High-Res Print (4x PNG)**: 4x nearest-neighbor scaled PNG image.
4. **Game Asset Sprite Sheet**: Grid sprite sheet layout.
5. **Animated GIF**: 2x scaled animated GIF for social media previews.
6. **ZIP Distribution Package**: Project package containing JSON manifest and raw assets.
