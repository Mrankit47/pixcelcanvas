# Template Library Architecture

> **Phase**: 7 – Step 3  
> **Version**: 1.0.0

## 1. Built-in Templates Library

1. **16×16 Character Sprite**: hero sprite template with outline layers.
2. **32×32 Game Item Icon**: inventory icon template.
3. **64×64 RPG Tileset**: 64x64 terrain autotile grid.
4. **128×128 Animated Walk Cycle**: 8-frame walk cycle timeline template.
5. **32×32 Pixel Portrait**: dialogue avatar canvas.
6. **48×48 UI Component**: HUD health bar template.
