# Responsive Layout Architecture

> **Phase**: 7 – Step 1  
> **Version**: 1.0.0  

---

## 1. Breakpoint Specifications

- **Desktop Mode** ($\text{width} \ge 1024\text{px}$): Full multi-panel layout with expanded sidebar, top toolbar, workspace tab bar, and status bar.
- **Tablet Mode** ($600\text{px} \le \text{width} < 1024\text{px}$): Auto-collapses sidebar to compact icon drawer.
- **Mobile Mode** ($\text{width} < 600\text{px}$): Hides status bar and sidebars into bottom modal sheets.
