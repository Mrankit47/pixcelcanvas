# Navigation Architecture

> **Phase**: 7 – Step 1  
> **Version**: 1.0.0  

---

## 1. Overview

`NavigationManager` manages top-level application navigation routes and screen transitions.

---

## 2. Route Hierarchy

- **`dashboard`**: Welcome home screen listing recent projects.
- **`editor`**: Primary Pixel Canvas editor workspace.
- **`templates`**: Preset pixel art template chooser.
- **`gallery`**: Project showcase gallery.
- **`settings`**: Application preference settings.
- **`help`**: Documentation center.
- **Placeholders**: `community`, `cloud`, `marketplace`.
