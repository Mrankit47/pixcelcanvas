## 1. Primary Editor Commands

| Command Name | Category | Default Shortcut | Description |
|--------------|----------|------------------|-------------|
| **Undo Edit** | Drawing | `Ctrl+Z` | Reverts most recent pixel edit or layer command |
| **Redo Edit** | Drawing | `Ctrl+Y` | Redoes previously undone command |
| **Select Brush Tool** | Tools | `B` | Activates single-pixel brush tool |
| **Select Eraser Tool** | Tools | `E` | Activates pixel eraser tool |
| **Select Bucket Fill** | Tools | `G` | Activates flood fill tool |
| **Command Palette** | Navigation | `Ctrl+K` | Opens searchable quick command modal |
| **Save Project** | Project | `Ctrl+S` | Saves current workspace project file |
| **New Project** | Project | `Ctrl+N` | Opens project creation wizard |
| **Export Image** | Export | `Ctrl+E` | Opens export configuration dialog |
