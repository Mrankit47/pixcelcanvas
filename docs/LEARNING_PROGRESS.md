# Learning Progress & Achievements Architecture

> **Phase**: 7 – Step 5  
> **Version**: 1.0.0  

---

## 1. Overview

`TutorialProgressManager` tracks learning progress:

- **Completion Percentage**: Calculates percentage of completed tutorials across categories.
- **Achievements Unlocked**: Grants achievement badges upon completing tutorial milestones (e.g. `First Steps`, `Layer Master`, `Pixel Animator`).
